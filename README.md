# Autoescuela Meca — Ayora / Almansa

Site institucional e de alta conversão da **Autoescuela Meca** (Plaza Mayor, 1 · 46620 Ayora, Valencia · zona Almansa).

## Estrutura do Projeto

- `index.html` — Página principal responsiva em HTML5 semântico, CSS moderno e JavaScript vanilla.
- `assets/` — Logotipo oficial, favicon e fotografias reais da frota (veículo 100% elétrico Tesla, caminhão CAP) e alunos aprovados.
- `vercel.json` — Configuração de URLs limpas, cache de assets e headers de segurança HTTP.
- `docs/` — Documentação estratégica de apoio (`dossie_autoescola.md`).
